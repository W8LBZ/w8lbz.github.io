# w8lbz.github.io

The club's site is https://w8lbz.org/; this address forwards there (`index.html`, and `404.html` for any other page).

UV Studio+ moved to https://ko4cgq.github.io/uvstudio-plus/ (repo: github.com/KO4CGQ/uvstudio-plus). This site only forwards
old links: any `w8lbz.github.io/uvstudio/...` address goes to the same page there (`404.html`, `uvstudio/index.html`; the front
page opens on the Live Viewer, `#live`), and `sw.js` removes the old offline copy from browsers that installed the app.
